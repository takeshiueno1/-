# 勤務表・交通費入力改善 設計書

## 1. 目的

勤務表の削除、時間計算、業務内容コピー、紙印刷と、交通費の金額・詳細・Excel出力を、利用者が迷わず操作できる状態へ改善する。

## 2. 勤務表

### 2.1 削除確認

- 確認文字列と現在パスワードは、ダイアログを開くたびに空欄で開始する。
- ブラウザーの資格情報自動補完によって社員コードやパスワードが自動入力されないようにする。
- 削除成功後はホーム画面へ戻り、「YYYY年M月の勤務表を削除しました。」と表示する。
- 削除は従来どおり論理削除とし、確認文字列・再認証・監査記録を維持する。

### 2.2 勤務時間の即時計算

- 始業、終業、休憩、休暇種別の編集中に、平日・休日の労働時間を画面上で即時計算する。
- 15分丸め、日跨ぎ、半休、健康診断、全日休暇の規則はBackendの`WorkTimeCalculator`と一致させる。
- 画面計算は入力確認用とし、保存時にはBackendが再計算した値を正とする。
- 不完全または不正な入力は計算値を空欄にし、既存の入力エラー表示を使用する。

### 2.3 業務内容コピー

- 業務内容が入力された行から、明示的な「出勤日にコピー」操作を実行できる。
- コピーは何度でも実行でき、会社休日・全日休暇を除く出勤日だけを対象とする。
- 実行前に確認を表示し、コピー後は保存前であることを通知する。
- 全日休暇の業務内容を空欄・入力不可とする既存規則は維持する。

### 2.4 紙印刷

- 「印刷」はブラウザーの印刷ダイアログを開き、コピー機またはプリンターへ紙出力する。
- A4縦、1ページ幅、Excel勤務表と同じ項目順・罫線・集計・署名欄で印刷する。
- ヘッダー、メニュー、操作ボタン、入力補助、エラー表示は印刷しない。
- 画面上で編集中の値と即時計算値を印刷対象とする。

## 3. 交通費

### 3.1 金額入力

- 鉄道・バス・その他の金額は、値が0の場合に空欄表示する。
- 利用した交通手段だけ、1円単位の0以上の整数を自由入力できる。
- 小数、負数、文字列、Java整数範囲外、往復計算後のオーバーフローをFrontendとBackendで拒否する。
- すべて空欄または0円の明細は申請・Excel出力できない。

### 3.2 詳細モーダル

- 表内の狭い詳細入力欄を、概要表示と「詳細を入力」ボタンへ置き換える。
- ボタンから500文字まで入力できるモーダルを開き、文字数、保存、キャンセルを表示する。
- キャンセル時は編集前の値を保持し、保存時だけ明細へ反映する。

### 3.3 Excel出力と申請

- Excel出力をリンクではなくボタンにする。
- 編集可能な申請では、明細・承認者の入力を検証し、エラーがあれば出力しない。
- 検証成功時は最新の明細を保存してからExcelをダウンロードする。
- Backendも出力直前に申請内容を検証し、不正な下書きのExcel生成を拒否する。
- 申請ボタンの表示は「申請」とする。再認証と電子印・監査履歴は維持する。

## 4. テスト

- Frontend単体テストで勤務時間プレビュー、コピー対象、金額文字列、オーバーフロー、Excel出力可否を確認する。
- Backend単体テストで交通費の金額上限と不正下書きのExcel出力拒否を確認する。
- ブラウザーで削除欄の初期空欄、削除通知、即時計算、コピー、詳細モーダル、Excelボタン、申請ラベルを確認する。
- 印刷プレビュー相当のCSSとA4レイアウトを確認し、実際のコピー機選択は利用者の端末で最終確認する。

## 5. 互換性

- DBスキーマ、交通費承認状態、既存APIパスは変更しない。
- Dockerは開発・結合試験専用、本番はJava 21・Tomcat 11・PostgreSQL 17向けWARを維持する。
