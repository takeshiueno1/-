# Codexペット作業完了通知 設計書

## 目的

Codexの作業終了を見落とさないように、デスクトップ上のペット「ブー」の近くへ、視認性の高い吹き出しと通知音を表示する。

本機能は勤怠管理システムの画面機能ではなく、この端末上のCodex作業を補助するローカル通知機能として実装する。

## 対象範囲

- Codexのターン終了通知フックを受け取るローカルスクリプトを追加する。
- 既存のCodex終了通知処理を維持したまま、ブー用の吹き出し通知を追加する。
- Codexのローカル設定で、新しい通知スクリプトを呼び出す。
- ペット画像、スプライトシート、勤怠管理システム本体は変更しない。

## 表示仕様

### 正常終了

- 文言は「作業完了！」とする。
- 緑色のチェックマークを付ける。
- 黄色系の背景、太い縁取り、大きな文字を使い、通常の通知より目立つ表示にする。
- ブーの保存済み表示位置を参照し、原則としてブーの左上付近へ表示する。
- 画面外にはみ出す場合は、使用中ディスプレイの表示領域内へ補正する。

### 要確認終了

- 終了通知から異常または確認要求を判定できる場合は、「作業を確認してください」と表示する。
- 判定に必要な情報が通知フックへ渡されない場合は、誤判定を避けて正常終了と同じ「作業完了！」を表示する。

### 表示時間と操作

- 表示時間は20秒とする。
- 吹き出しをクリックすると直ちに閉じる。
- 最前面へ表示するが、利用中のアプリケーションからキーボードフォーカスを奪わない。
- 同時に複数の終了通知を受けた場合は、表示を重ねず、最新通知の表示時間を更新する。

## 通知音

- 表示開始時にWindows標準の通知音を1回鳴らす。
- 外部音声ファイルや追加ライブラリには依存しない。
- 音声再生に失敗しても吹き出し表示は継続する。

## 構成

1. Codexがターン終了時に通知フックを実行する。
2. 追加するラッパースクリプトが、既存の終了通知コマンドを先に呼び出す。
3. ラッパースクリプトがCodexのローカル状態からブーの表示位置を読み取る。
4. 独立した通知プロセスが吹き出しと通知音を処理する。
5. 吹き出しは20秒経過またはクリックで終了する。

## 障害時の扱い

- 既存通知コマンド、位置情報の読取り、吹き出し表示、通知音は個別に例外処理する。
- ブーの位置を取得できない場合は、主画面の右下へ表示する。
- 通知処理の失敗をCodexへ異常終了として返さず、作業結果に影響させない。
- 診断に必要な最小限の情報だけをローカルログへ記録し、プロンプト本文や認証情報は記録しない。

## セキュリティと保守性

- 通知フックから受け取る文字列をコマンドとして再評価しない。
- Codexの認証情報や会話本文を表示・保存しない。
- 既存の通知実行ファイルのパスは設定から明示的に渡し、任意の実行ファイルを探索しない。
- Codex更新で内部状態の形式が変わっても、位置取得失敗時の右下表示へフォールバックする。
- 元の通知設定をバックアップし、手動で元へ戻せるようにする。

## テスト方針

- 正常終了通知で「作業完了！」が表示されること。
- 表示開始時に通知音が鳴ること。
- 20秒後に自動で閉じること。
- クリックで直ちに閉じること。
- ブーの位置情報がない場合も画面内へ表示されること。
- 通知データに特殊文字が含まれてもコマンドとして実行されないこと。
- 通知表示に失敗しても既存のCodex終了通知とCodex本体に影響しないこと。
- 実装後、このタスクの最終完了時に実通知を発生させ、ユーザーが表示と音を確認できる状態にする。

## 完了条件

- Codexの作業終了時に、ブーの近くへ目立つ吹き出しが表示される。
- 吹き出しは20秒表示され、クリックでも閉じられる。
- Windows標準通知音が1回鳴る。
- 既存通知とCodex本体の動作を妨げない。
- 設定の復元手順が用意されている。
