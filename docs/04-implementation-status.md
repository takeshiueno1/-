# 初版MVP 実装状況

## 実装済み

- セッション認証、CSRF対策、bcryptパスワードハッシュ
- 5回のログイン失敗による15分ロック
- 専用画面による本人用パスワード変更
- 安全な仮パスワードの自動生成、初回変更の強制、API側での未変更時アクセス拒否
- ログイン画面とAPIの入力検証、日本語エラー表示
- アカウント存在有無を開示しない管理者向けログイン情報再発行依頼
- 登録済み月の一覧から過去の勤怠を参照・編集
- ログイン中の氏名・社員コード・所属を画面右上に表示
- 管理者専用の利用者一覧、作成、有効化・無効化、パスワード再設定
- 本人の勤務表だけを扱う通常認可と、管理者による対象社員の切替・代理更新
- 管理者による他社員の参照・更新操作の監査記録
- 会社カレンダーPDFから会社休日を抽出し、新規作成・再初期化時の既定値へ反映
- 対象月の初期化、土日・祝日・会社休日の反映
- Pマーク運用確認日、WG参加可否
- 始業、終業、休憩、休暇、業務内容、システム番号の入力
- Excel準拠の15分丸め、日跨ぎ、警告、休暇換算
- 平日・休日時間、所定日数・時間、過不足、半休、案件別集計
- Excel形式に対応する月間表示と印刷表示
- 元Excelの見出し、罫線、休日行、月間表、案件別集計、所定時間・過不足、承認欄を一枚帳票として再現した画面
- 時刻の4桁入力補助（例: `1800` を `18:00` に変換）
- 休憩時間を時間形式で表示・入力（例: `1:00`）
- スマートフォン向け日次カード表示
- 勤務表初期化、日次更新、WG変更、アカウント管理、パスワード変更の監査記録
- PostgreSQLマイグレーションとDocker Compose起動
- ログイン直後の「新規作成」「過去参照・編集」選択画面
- 勤務表以外の黒・黄・白によるクエリ配色
- 管理者限定の社員検索
- パスワード付き `.xlsm` を含む過去Excel勤務表の取込と取込監査情報
- 一般利用者による本人の過去Excel勤務表取込と、登録直後の画面反映
- 確認文言と操作ユーザー本人のパスワード再認証を伴う勤務表の論理削除
- 環境変数で明示的に有効化する50人・6か月分のローカル負荷検証データ

## 初版後に追加する候補

- 前日コピー、期間一括適用、最近使用した案件候補
- 1日複数案件への時間配賦画面
- 祝日・会社休日・システム番号の管理画面
- 監査ログ閲覧画面
- パスキーまたは社内SSOによるパスワードレス認証
- VPN、TLS、バックアップを含む社内サーバー導入設定
- 正社員・8時間勤務以外のExcel帳票対応
- 提供済みレイアウト以外のExcel移行
- 画像だけで構成された会社カレンダーPDFのOCR取込

## 現時点の制約

- 電子承認、提出、差戻し、月次締めはExcelに状態遷移仕様がないため実装していない。
- 給与・会計システム向け出力は要件どおり実装していない。
- VPNとTLSは社内サーバー・ネットワーク構成の確認後に設定する。
- パスワードレス認証は本番のホスト名、TLS、利用可能な社内ID基盤が未確定のため未実装。端末指紋による代替は本人性が弱く採用しない。
- 初期管理者パスワードは初回起動時だけ環境変数から登録され、以後は画面から変更する。
- PDF取込後に作成済み勤務表へ休日を反映する場合は、入力消失の確認付き再初期化が必要となる。
- Excel取込は提供済みの「勤務表」シート配置を対象とし、別レイアウトは個別マッピングが必要となる。
- ローカル検証データは `APP_DEMO_SEED_ENABLED=true` の場合だけ作成し、本番では無効にする。
