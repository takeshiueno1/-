# Excel忠実再現 合格基準

## 1. 基準

初版は提供された正社員・8時間勤務のExcelを基準とする。入力項目、初期値、計算結果、警告、集計結果、印刷時の帳票構成に加え、利用者の移行負担を抑えるため、濃いグレーの見出し、罫線、白い入力セル、休日行、月間表と下部集計の配置を踏襲する。ブラウザ固有の保存操作などを除き、勤務表部分はExcelを見慣れた利用者が迷わないことを「忠実な再現」と定義する。

## 2. 月次初期化

- 対象年月から1日から月末までの日付と曜日を生成する。
- 標準始業時刻、標準終業時刻、休憩1時間、標準システム番号を平日に設定する。
- 土曜を指定休日、日曜を普通休日として勤務入力を空欄にする。
- 祝日・会社休日マスターに該当する日を休日として設定する。
- Pマーク運用確認日を翌月最初の営業日にする。
- 初期化時に既存入力が消える場合は、Excelと同様に事前確認する。

## 3. 日次計算

- 始業分は15分単位で切り上げる。
- 終業分は15分単位で切り捨てる。
- 休憩分は15分単位で切り上げる。
- 労働時間を終業－始業－休憩で算出する。
- 終業が始業より前の場合は日跨ぎとして24時間を加算する。
- 日曜勤務は休日労働時間へ計上する。
- 10:00より後の始業、16:00より前の終業を警告する。
- 平日の必須項目未入力を警告する。

## 4. 休暇計算

- AM半休、PM半休、有給休暇、特別休暇、慶弔休暇、振替休日、欠勤を選択できる。
- 有給休暇、特別休暇、慶弔休暇は所定労働時間として計上する。
- 半休は所定労働時間の半分を休暇、残りを勤務として集計する。
- 休暇種別に応じてExcelと同じシステム番号へ振り替える。
- 健康診断の特別処理を再現する。

## 5. 月次集計

- 平日労働時間と休日労働時間がExcelと一致する。
- システム番号別の日数と時間がExcelと一致する。
- 半休回数、所定日数、所定時間、過不足時間がExcelと一致する。
- 案件集計が5件を超えても欠落しない。

## 6. 表示・帳票

- 所属、氏名、役職、社員コード、対象年月を表示する。
- Pマーク運用確認日、WG参加可否を表示する。
- 日付、勤務時間、労働時間、休暇、業務内容、システム番号を月間一覧で確認できる。
- Excelの月次集計欄と確認欄に対応する印刷表示を用意する。
- スマートフォンでは日次入力が横スクロールに依存せず操作できる。

## 7. 照合テスト

同じ入力をExcelとシステムへ登録し、少なくとも次のケースを照合する。

1. 通常勤務
2. 始業・終業分の15分丸め境界値
3. 遅い始業と早い終業の警告
4. 日跨ぎ勤務
5. 土曜勤務、日曜勤務、祝日勤務
6. AM半休、PM半休
7. 有給休暇、特別休暇、慶弔休暇、振替休日、欠勤
8. 健康診断
9. システム番号が複数ある月
10. 28日、29日、30日、31日の各月

代表ケースだけでなく、丸め境界値の0、1、14、15、16、29、30、31、44、45、46、59分を自動テストする。
