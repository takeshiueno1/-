## 2. 確認できた現行業務

### 月次設定

- 対象年月、標準始業・終業時刻、標準システム番号を設定し、「適用」で当月の日付を生成する。
- 土曜は「指定休日」、日曜は「普通休日」として設定する。
- `祝日` シートの会社休日・祝日を勤務表へ反映する。
- Pマーク運用確認日は翌月最初の営業日に自動設定する。
- WG参加可否は「参加」「不参加」「当月未開催」から選ぶ。

### 日次入力

- 始業時刻
- 終業時刻
- 休憩時間
- 休暇種別
- 業務内容
- システム番号（案件・社内活動等のコード）

### 自動計算・入力チェック

- 始業時刻と休憩時間の分は15分単位で切り上げる。
- 終業時刻の分は15分単位で切り捨てる。
- 労働時間は「終業－始業－休憩」で算出し、日跨ぎの場合は24時間を加算する。
- 10:00より後の始業、16:00より前の終業は赤字・太字で警告する。
- 平日の必須入力が空欄の場合は背景色で警告する。
- 日曜の勤務時間は平日欄ではなく休日欄へ計上する。
- 平日勤務でシステム番号が空欄の場合は標準システム番号を設定する。

### 休暇処理

- 選択肢: AM半休、PM半休、有給休暇、特別休暇、慶弔休暇、振替休日、欠勤。
- 有給休暇、特別休暇、慶弔休暇は所定労働時間として扱う。
- 半休は所定労働時間の半分を休暇、残りを勤務として集計する。
- 有給休暇等は固定のシステム番号へ振り替える。
- 健康診断は業務内容の文字列を基に特別処理する。

### 月次集計

- 平日労働時間、休日労働時間を合計する。
- システム番号単位で日数・時間を集計する。
- 半休回数、所定日数、所定時間、過不足時間を算出する。
- 取締役、上長または担当リーダー、総務部の確認欄がある。

## 3. 現行方式の制約・リスク

- マクロとセル位置に業務ルールが密結合しており、レイアウト変更で壊れやすい。
- システム番号別集計の表示枠が5件に固定されている。
- 1日につき実質1つのシステム番号しか登録できない。
- 祝日・会社休日はExcel内の一覧を手動保守する必要がある。
- シート保護用パスワードがVBA内に平文で埋め込まれており、アクセス制御としては使用できない。
- Excelファイル単位の運用では、同時編集、承認履歴、変更履歴、提出状況の一元管理が難しい。
- Pマーク確認、WG参加可否、健康診断など、勤怠本体とは別の業務ルールが混在している。

## 4. システム化時に維持する計算ルール

初版では、分析対象Excelの以下のルールを変更せずに再現する。Excelマクロには6時間勤務、7時間勤務、協力会社、日給などの分岐も存在するが、提供された帳票は正社員・8時間勤務である。他の帳票種別は実物の提供を受けてから対象範囲を確定する。

- 15分単位の切り上げ・切り捨て
- コアタイム警告（10:00、16:00）
- 所定労働時間（現行サンプルは8時間、マクロ上は6時間・7時間にも対応）
- 日曜勤務の休日労働扱い
- 半休・各休暇の時間換算とシステム番号への振替
- 会社休日を含む営業日カレンダー
- 所定時間との差分計算
